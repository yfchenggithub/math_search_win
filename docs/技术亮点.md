# 技术亮点一页纸

> 高中数学二级结论搜索系统 | Qt 6.11 + C++17 + MSVC 2026 | 离线桌面应用

---

## 架构

```
UI (Qt Widgets) → Domain Services → Repositories → Infrastructure (JSON/QSaveFile)
                      ↑ License System (Activation → FeatureGate → 5 flags)
```

- **分层架构**：UI / Service / Repository / Infrastructure 四层，依赖方向单向
- **6 页面**：首页、搜索、收藏、历史、设置、激活，QStackedWidget 管理
- **15 个 CTest** 自动化测试用例

---

## 核心功能

### 搜索引擎（自建）
```
Query → normalize → termIndex(精确) + prefixIndex(前缀)
     → fieldMask 加权(intent/title/keyword)
     → 交叉增强(同doc多字段命中加分)
     → module过滤 → 排序(相关度/标题/难度) → Top N
```
- 数据量 ~2MB 索引 + ~5MB 内容，全内存加载，毫秒级响应
- 不用 SQLite FTS：数学符号分词难、离线全内存更快

### 建议系统（三重来源 + 质量门控）
```
人工种子 → domain/topic层级扩展 → prefix/term回退
    → 过滤(未闭合括号 + 语义截断前缀) → 评分 → Top 8
```

### 详情渲染（4 路径自动切换）
```
PDF (QPdfView MultiPage) → Web (QWebEngineView + KaTeX)
    → Fallback (QTextBrowser) → Trial (截断预览)
```
- 优先 PDF，失败自动回退，用户无感知
- Ctrl+滚轮连续缩放，F11 全屏

## Qt 核心技术栈

| 技术 | 用途 |
|------|------|
| QWebEngineView | KaTeX 数学公式渲染 |
| QPdfView + QPdfDocument | PDF 详情阅读（MultiPage，页码导航，导出） |
| QStackedWidget | 6 页面切换 |
| QSaveFile | 原子写盘防数据损坏 |
| Signal/Slot | 跨页面收藏/历史联动 |
| eventFilter | Ctrl+滚轮字体缩放 |
| QCryptographicHash | SHA-256 设备指纹 |
| QWebEngineProfile | 自定义 WebEngine 缓存路径 |

## C++ 工程实践

- C++17：`std::optional`, `if constexpr`, 结构化绑定
- 前向声明 + 命名空间隔离，减少头文件依赖
- RAII / QObject 树管理生命周期
- const 正确性，enum class 类型安全
- 统一日志系统（18 个分类 + 双通道输出）

## 授权系统

```
激活码(MSW1.payload.crc32) → 解析 → 设备指纹绑定 → license.dat → FeatureGate(5 flags)
状态机: Missing → Trial → ValidFull → Expired → Invalid
```
